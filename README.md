# YouTube Live Chat Lightweight Ticker

## Overview

A browser extension that reduces CPU usage by throttling YouTube Live's chat ticker.

YouTube attempts to refresh the ticker as frequently as possible (often at 60 FPS); this extension limits updates to every 2 seconds.

Only the ticker's refreshes are affected; other page rendering and animations remain unchanged.
